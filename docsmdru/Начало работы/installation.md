# Установка Ely
**Ely не запрещает сторонние компиляторы, однако в документации мы рекомендуем использовать основной компилятор ElySpruce для актуальности и надёжности.**

## Установите компилятор ElySpruce
#### 1. Перейдите на <a href="https://ely-language.github.io/">официальный сайт</a> Ely, во вкладку "Версии"
![installhelperimg1](./assets/installation/install1.png)
#### 2. Выберите подходящую вам версию (рекомендуем последнюю)
**Выберите версию:** вы можете выбрать любую версию последнего стандарта (или других), или просто скачать последнюю версию кнопкой слева.
**Вас перекинет в GitHub-релиз версии,** просто нажмите на подходящий вам установщик:
![installhelperimg2](./assets/installation/install2.png)
Затем версия будет скачана.
#### 3. Установите компилятор с помощью мастера установки.
#### 4. Проверьте работоспособность:
Компилятор, как правило, сразу после установки можно использовать в консоли. Попробуйте:
```bash ebt``` - эта команда должна вывести все комманды языка. В случае, если произошла ошибка, попробуйте перезапустить компьютер. Если и тогда не получится, добавьте корневой каталог компилятора в PATH вручную

## Установка C++ компилятора
Если у вас нет компилятора для C++, установите CLANG или G++ с официальных сайтов.

## Создайте свой проект
Перейдите в папку, в которой хотите создать проект, и пропишите в консоли или терминале:
`bash ebt project [название_проекта]`
Должна появиться следующая структура:

![installhelperimg5](./assets/installation/install5.png)
#### Этой структуры достаточно для вывода "Hello World!".
Зайдите в файл main.ely.
Там будет такой код:
```go
public int func main() {
    println("Hello from ely!");
    return 0;
}
```
Давайте заменим "Hello from ely!" на привычные всем строки "Hello World!":
```go
public int func main() {
    println("Hello World!");
    return 0;
}
```
Теперь, давайте скомпилируем и запустим проект:
выполните в корне проекта в консоли `bash ebt run manager.json`
#### Вывод компилятора должен быть таким:
```console
✓ Analysis successful
✓ Executable created: [путь]
Hello from ely!
```
