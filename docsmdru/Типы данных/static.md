# Статическая типизация
Как вы поняли, статическая типизация очень важна для производительности и скорости работы.
#### В языке Ely есть большое разнообразие типов
В основном их можно разделить на три направление: целые числа (int), вещественные числа (flt) и символьные значения (строки - str).
#### При объявлении переменных всех типов кроме `any` тип указывать ОБЯЗАТЕЛЬНО

## Целые числа
В языке есть несколько типов для целых чисел. Взаимодействие меж ними осуществляется бесшовно.
| тип   | описание | диапозон значений | вес | 
|-------|---------------------------|----------------------|-----|
| int | стандартное число на 32 бита | от -2 147 483 647 до 2 147 483 647 | 32 бита (4 байта) |
| byte | уменьшеное число на 16 бит | от -32 767 до 32 767 | 16 бит (2 байта) |
| more | увеличенное число на 64 бита | от -9 223 372 036 854 775 807 до 9 223 372 036 854 775 807 | 64 бит (8 байт) |

### Интересный факт: диапозон значений для типа (кроме неотрицательных) вычисляется по формуле:
#### M = (2^i - 2) / 2
Где M - модуль крайних значений диапозона, i - объём памяти в битах
### Работа
#### Пример объявления
```go
int a = 2;
```
#### В дальнейшем (после объявления) тип указывать не нужно:
```go
int a = 20;
int b = a + 10;
```
#### Работа меж подтипами безопасна:
```go
int a = 2;
byte b = 3;
more c = 4;
print(intToStr(a+b+c));
```
**!К сожалению, компилятор плохо работает с генерацией вывода и значения нужно преобразовывать самостоятельно. Начиная с версии 26.5 сборок выше 185 проблема будет исправлена. То же касается вывода вещественных чисел. Просим прощения за неполадки.**

## Вещественные числа
Вещественные числа - числа с плавающей точкой, также известны, как float. В языке существует два типа для этих чисел: flt и double, а также noised, который находится в разработке.
#### Различия
Единственное различие меж flt и double - их максимальный размер. Поскольку эти числа дробные, мы не можем точно описать диапозон их значений, ведь они хранят обе части. Но, если упростить, **double больше и весомей flt примерно в 2 раза, однако, для большинства задач, flt достаточен.** 
#### Объявление
```go
flt a = 2.1;
double b = 2.5;
```
#### Вещественные числа совместимы в операциях с целыми и между подтипами.
**!Ещё раз напоминаем, что в версиях, не новее 26.5 сборки 185 вещественные числа на выводе преобразуются в целые. Работаем над решением!**

## Строки
Строки технически должны были быть на следующей странице, но, для простоты, обсудим их тут.
#### Есть два типа строк: char (один символ) и str (строка)
#### Объявление:
```go
char a = "a";
str myStr = "Hi, there!";
```
### F-строки и мнострочность
В языке также есть привычные всем особенности:
#### Многострочная строка
```go
str multiline = """
multiline
string
"""
```
#### F-строки - внутренние значения
```go
public int func main() {
    int num = 3;
    str name = f"User{intToStr(num)}"; // f-string
    str hello = f"""
    Hello, {name}!
    """;
    print(hello);
}
```
Вывод:
```console

Hello, User3!

```
