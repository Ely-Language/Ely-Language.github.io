# Динамическая типизация
## О типизации
Как вы уже знаете, в Ely есть динамическая типизация. 
#### Для простоты входа новичка, мы рекомендуем начинать именно с неё.
**Динамическая типизация - случай, когда можно объявлять и менять тип переменных на ходу программы.** Обычно, динамика встречается в интерпретируемых языках (как Python или JavaScript) и (или) в языках с Just-in-Time компиляцией (как C# и Java). Однако, Ely - язык, компилируемый Ahead-of-Time, что делает, на первый взгляд, динамику невозможной. Но она есть.

## Any
`any` - тип данных динамической типизации. Все динамически типизированные переменные в языке числятся как `any`. *Такое название он получил с раннего этапа разработки парсера, когда язык планировался как статически-типизированный, ведь должен был быть обычным автовыводом типов.*
#### Смена типов на ходу не значит их отсутствие!
В Ely можно сделать так:
```go
any a = 5;
any a = "Hi!";
```
Но так нельзя:
```go
any a = 5;
any b = "Hi!" + a; // Error
```
#### Поэтому, мы советуем преобразовывать типы везде, где это возможнно:
```go
any a = 5;
any b = "Hi!" + intToStr(a); // Correct
```
#### Подробнее о преобразованиях можете прочитать на странице документации "Преобразование" во вкладке "Встроенное"

## Ленивая типизация
Однако, в языке допустима и приветствуется **Ленивая типизация**, как в Python: вы можете не указывать `any` для объявления статических переменных:
```go
a = 5;
b = "Hi!" + intToStr(a);
```
Этот пример должен работать.

## Главные недостатки
Динамика - не самый лучший вариант для вас, если вы хотите скорость и 100% уверенность в работе.
