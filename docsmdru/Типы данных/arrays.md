# Массивы
**Массивы - ещё одна часть фундамента любого современного языка. Они позволяют хранить в одной переменной сразу несколько значений, привязанных к индексам.** Это позволяет делать невероятные вещи. Мало того, строки - лишь массивы из символов (char)!
## Обычный массив Array
Конечно, это не единственный массив, но именно его мы так будем называть далее. Array - массив, который может быть как статически, так и динамически типизирован. Объявлять его можно двумя способами, которые никак не повлияют на работу.
### Статический массив
Объявляется двумя способами:
```go
int[] myIntArr = [2, 3]; // int arr
arr<int> mySecondIntArr = [2, 3];
```
Эти объявления на уровне языка одинаковы, и создают массив, строго заточенный только под целые числа int, и со старта хранит значения 2 и 3. Однако второй способ работает более надёжно и проверен куда лучше. 
#### Массивы работают с любыми типами данных
### Динамический массив
```go
arr dynArr = ["1", 2];
```
Это объявление однозначно с:
```go
arr<any> dynArr = ["1", 2];
```
### Работать с элементами массива можно так:
```go
arr<int> a = [1, 2, 3];
int aOne = a[0]; // 1
```
Как и везде, нумерация индексов начинается с 0.
В данном примере мы передаём `aOne` значение из `a`, имеющее индекс 0, то есть - `1`.
### Функции
Для работы с массивами есть немалое количество функций, вот самые важные из них:
```go
arr<int> a = [1, 2];
a.append(3);
a.remove(3);
```
`append` добавляет новый элемент в конец списка, `remove` удаляет первый найденный элемент, равный указанному (в примере удалит первую по индексу 3).

## Словари
В Ely, как и в Python, есть словари, причём в том же виде. Однако, из-за наличия статики, можно создавать статические словари с фиксированным типом ключей или значений.
### Статический словарь
```go
dict myDict<str, int> {
    "first": 1,
    "second": 2
}; // str: int
print(intToStr(myDict.first));
```
Стоит заметить, что так использовать можно словари только в том случае, когда ключи типа `str`. В других случаях:
```go
dict myDict<int, str> {
    1: "first",
    2: "second"
}; // int: str
print(intToStr(myDict[1]));
```
### Динамический словарь
Динамический словарь почти идентичен статическому, легче в использовании, однако он занимает больше места по умолчанию:
```go
dict myDict {
    "first": 1,
    "second": 2.0,
    "third": "3"
};
```
Однако, для предсказуемости, мы рекомендуем использовать полудинамические словари в духе Python:
```go
dict myDict<str, any> {
    "first": 1,
    "second": 2.0,
    "third": "3"
};
```
Это аналогично предыдущему примеру по содержанию, но немного легче и быстрее. В этом случае ключи могут быть только строками.
### Использование
```go
public int func main() {
    int[] ar = [2, 4];
    dict<str, any> a = {
        "first": 1
    };
    a["second"] = 2;
    print(intToStr(a.second));
}
```
Вывод:
```console
2
```
